# auth-app-practice

## 概要
COACHTECH 教材 Tutorial 10-1「認証機能 ハンズオン演習」で作成した成果物です。
Laravel Fortifyを使ったログイン・ログアウト・ユーザー登録機能と、認証が必要なダッシュボードを作成しました。

## 使用技術
- PHP 8.x
- Laravel 10.x
- Laravel Fortify（認証）
- MySQL

## 学んだこと
- リダイレクト先の設定方法
- 認証済みのユーザーのみがアクセスできるページの作成（ DashboardController）

## 動作確認
ブラウザで http://localhost/register にアクセスし、ユーザー登録画面が表示されるか確認します。また、以下の4点ができれば成功です.

- ユーザー登録ができる
- ログイン・ログアウトができる
- ダッシュボードでの自分の情報の確認
- 未ログイン時やログアウト時のリダイレクトが正常に行われる
